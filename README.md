# BUAD — بُعد

Company website of **BUAD (بُعد)** — an integrated management, development & operations ecosystem, Makkah, Saudi Arabia.

- Static site (HTML / CSS / vanilla JS), no build step.
- Arabic (RTL) by default, English via the language button (`?lang=en` also works).
- Hero: a day-to-night time-lapse of the Al Jumum Interface project, built from six project renders.

## Run locally
```
python -m http.server 8765
```
then open http://localhost:8765

## Publish (GitHub Pages)
Settings → Pages → Deploy from branch → `main` / root.
